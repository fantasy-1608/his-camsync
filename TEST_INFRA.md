## 1. Overview & Architecture

The HIS CamSync End-to-End Testing Infrastructure provides an automated, multi-tiered verification harness for medical image capture, clinical watermarking, real-time chunked transfer, and hospital HIS form injection.

To comply strictly with the Vietnamese Personal Data Protection Law (Luật BVDLCN 2025) and VNPT HIS safety regulations, the testing suite operates under **Zero-PHI Isolation**: 100% of test assets (ECG rhythm strips, ultrasound phantoms) are algorithmically generated by synthetic mathematical generators without using any real patient data.

## 4. Synthetic Clinical Data Generators

Located in `tests/e2e/generators/clinical-synthesizer.js`:

1. **Synthetic Lead II ECG Generator (`generateSyntheticEcg`)**:
   - Generates true millimeter grid lines (1mm minor pink grid, 5mm major red grid) on a 2D canvas buffer.
   - Plots mathematical P-QRS-T complexes:
     - P wave: smooth sine bump (duration ~80ms, amplitude ~0.15mV)
     - Q wave: small downward dip
     - R wave: high-voltage spike (-120px)
     - S wave: negative overshoot
     - ST segment & T wave: repolarization deflection
   - Outputs an exact Region Of Interest (`ecgWaveformRoi`) bounding box used by Tier 4 to verify 0.0% pixel obstruction.

2. **Synthetic Ultrasound Phantom (`generateSyntheticUltrasound`)**:
   - Generates convex sector acoustic window with Rayleigh-scattered speckle pattern and depth attenuation.
   - Implants a central hypoechoic nodule / lesion and lateral calibration depth markers.

3. **High-Resolution Generator (`generate48MPImage`)**:
   - Produces 8000x6000 pixel buffers to verify memory-safe downscaling to the 1600px ceiling.

## 5. Mock Harnesses & Verification Tools

1. **Mock Realtime Broadcast Hub (`mock-realtime.js`)**:
   - Simulates Supabase Realtime Channels (`camsync:<session_id>`).
   - Validates 64KB chunk boundaries (`chunk_start`, `chunk_data`, `chunk_complete`, `transfer_ack`).
   - Provides `verifyZeroRetention()`: verifies that 0 bytes are ever written to disk and all transfers operate strictly in RAM.

2. **Canvas & Pixel Harness (`canvas-pixel-harness.js`)**:
   - Full in-memory RGBA pixel buffer implementation without native C++ compilation dependencies.
   - Standard JPEG JFIF header generator & validator (`0xFF 0xD8 0xFF 0xE0 ... 'JFIF'`).
   - `calculateWcagContrast()`: calculates WCAG AAA contrast ratio (>= 7.0:1) between white text (`#F8FAFC`) and capsule backdrop (`rgba(15, 23, 42, 0.80)`).
   - `measurePixelDiff()`: pixel-by-pixel ROI comparator.

3. **Mock VNPT HIS Server & DOM Harness (`mock-his-server.js` & `his-dom-harness.js`)**:
   - Simulates VNPT HIS browser context, patient banner, `#fileUpload` input, and `#btnUpload`.
   - Validates DataTransfer file injection and upload POST endpoints.

## 6. Execution Commands

### Running All Test Suites
```bash
node tests/e2e/run_all_tests.js
```

### Self-Test Validation Mode
```bash
node tests/e2e/run_all_tests.js --self-test
```

### Running Specific Tiers
```bash
# Run Tier 1 only (Feature Coverage - 35 tests)
node tests/e2e/run_all_tests.js --tier=1

# Run Tier 2 only (Boundary & Corner Cases - 15 tests)
node tests/e2e/run_all_tests.js --tier=2

# Run Tier 3 only (Cross-Feature Combinations - 8 tests)
node tests/e2e/run_all_tests.js --tier=3

# Run Tier 4 only (Clinical Real-World Scenarios - 5 tests)
node tests/e2e/run_all_tests.js --tier=4
```

- **Execution Speed**: 63 tests execute in under 0.5 seconds on standard hardware.

- **Waveform Integrity**: 0.0% pixel distortion inside the ECG waveform bounding box.
- **Zero-Retention**: 0 bytes written to disk; 0 database rows retained on cloud.
- **Zero-Leakage**: Direct REST probe with `anon` key is 100% blocked (HTTP 401).
